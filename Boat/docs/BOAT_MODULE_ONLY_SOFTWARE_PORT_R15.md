# R15 software module command gate (host-only)
- `Boat/source/premade_module_output_r15.h` is a **software-only request adapter** for the future commercially manufactured MDD20A and EKM014 I/O. It has **no hardware GPIO pin driver, no actuator wiring, no board profile enabled**, and cannot substitute for independent hardware time limiting or a physical DC cutoff.
- Until **all 10 independent module commissioning/physical acceptance flags** are true, no motor or release is passed. A fresh local trusted sample, no fault and physical STOP/cutoff/watchdog feedback are required every request. An active release produces only a *single software trigger edge* when a fresh zero-current idle interval of at least 50ms has been observed. Repeated held requests do not repeat, and a software fault latches. All limits are software-only simulation constants; actual values must follow measurement of the solenoids.
- This header is not wired into the live Heltec application intentionally. Integrate **only after** selecting actual premade current feedback, timer, and cutoff modules and commissioning actual Heltec pins. `Boat/tests/module_only_output_r15_test.cpp` checks default OFF, missing qualification, each of 4 outputs, stuck high, simultaneous motor/coil, stale telemetry and fault latch under a fake all-true qualification. Fake qualification is **not** authorization to activate live power.
