# R6.1 fit-test coupons — print before the full remote

These small test plates check printer/material tolerances and allow trial-fit with actual hardware before printing the controller shell. The nominal dimensions are provisional and should be tested using the final filament, nozzle, slicer settings and orientation.

## Coupon plates
1. **Button holes:** 13.8, 14.2, 14.6 and 15.0mm holes. Trial fit the chosen switch/button assembly.
2. **Joystick apertures:** 24.5, 25.0, 25.5 and 26.0mm. Compare to the actual joystick bezel/shaft.
3. **USB-C and screw plate:** slot matrix width 15.0/15.5/16.0mm × height 8.0/8.5/9.0mm; screw holes 2.8/3.0/3.2/3.4mm.
4. **Release guard:** two 21mm OD raised collars around 17.6 and 18.0mm openings; trial key travel, finger access and side-pressure behavior.

## Suggested print procedure
- Print each coupon flat, no supports.
- Use the same material and slicer settings intended for the enclosure. Suggested starting point: 0.20mm layer height and 3 perimeters; adjust for the printer/material.
- Measure printed holes/slots with calipers and record fit results.
- Guard rings do not replace electronic release confirmation or boat-side interlocks.

These coupons are a calibration aid only, not proof that the complete enclosure is dimensionally correct or safe.
