# Bulgarian UI build
Target CI generates DejaVu Sans 14 px with Cyrillic and copies the C resource and marker into the Arduino sketch. Montserrat is used as fallback for standard LVGL icons. For a local Arduino IDE build, first run `bash Remote/tools/generate_bg_font.sh` on a Linux/WSL host with Node and fonts-dejavu-core, then copy `out/ui-font/flytec_bg_14.c` and `flytec_bg_14.generated.h` beside `Flytec_Remote.ino`; retain the generated license file with the firmware source. Without the generated files, the diagnostic build falls back to Montserrat and logs a warning. Phonetic QWERTY-style Bulgarian lower/upper and English keyboard layouts are selectable; English includes its original numeric/symbol mode. Actual glyph coverage, keyboard interaction and 800x480 fit require target runtime verification.

Bulgarian layout rows: Я В Е Р Т Ъ У И О П Ш Щ / А С Д Ф Г Х Й К Л Ч / З Ь Ц Ж Б Н М Ю. All 30 letters are available; the extra Cyrillic keys are at row ends. English/numeric/symbol modes remain available. This is a touch-adapted phonetic layout, not a formal BDS compliance claim.
