# Flytec Remote R5 Preview

The SVG preview shows the agreed front-panel logic: central 4.3-inch display, two thumb joysticks, left 2×4 utility bank, right 2×4 bank with **H-L, H-R, K-L, K-R** in its top four positions, separate OK/confirm and power.

This is a layout illustration, not dimensionally certified CAD. Exact fit awaits measurements of the selected screen, joysticks, switches, antennas and battery.
